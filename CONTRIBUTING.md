# Contributing

Thanks for contributing to `ax-agent-core`.

## Development Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
make setup
```

## Local Workflow

```bash
make lint
make test
make demo
```

## Contribution Standards

- Keep pull requests focused and reviewable.
- Add or update tests for behavior changes.
- Update docs/config examples for user-facing changes.
- Use clear commit messages that explain intent.

## Pull Request Checklist

- Tests pass locally.
- Lint and type checks pass.
- No secrets or credentials are committed.
- Changelog updated for meaningful behavior changes.
